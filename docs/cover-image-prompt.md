# GPT 封面图提示词

实际封面与视觉参考见 [assets/cover.jpg](../assets/cover.jpg)。

## 作用

用于为「拓扑」技能生成 GitHub 仓库封面、文档头图或技能展示图。画面应直观传达“分组节点、主链路、普通依赖、辅助关系和备注”的信息可视化主题，同时避免生成乱码文字。该图片仅用于展示，不是页面运行或 JPG 导出的依赖。

## 提示词

```text
请生成一张 16:9 横向、高分辨率、适合开源项目封面的专业信息可视化矢量插图。

主题：通用节点关系拓扑与系统架构图。

画面采用浅灰点阵背景，横向、宽幅、松散的多列布局。放置四个边界清晰的圆角矩形分组框，分别使用浅蓝、浅紫、浅绿、浅米白底色。每个分组内包含若干白色或极浅色圆角矩形节点，节点大小一致、间距充足、层次清楚。

用橙色粗实线箭头贯穿主要节点，形成醒目的核心链路；用蓝色细实线箭头表示普通依赖；用少量灰色虚线箭头表示辅助或可选关系。所有连线使用水平或垂直的正交路径，避免穿过无关节点。加入一个简洁的自关联回环和一组可辨认方向的双向箭头。少量节点旁放置黄色小型圆角备注标签。右下角放置简洁的小型图例区域。

整体风格：简洁、专业、现代、扁平化矢量、视觉层级清晰、留白充足、柔和配色、边缘锐利、适合高清展示。

严格限制：不要品牌，不要 Logo，不要人物，不要三维渲染，不要炫光，不要复杂渐变，不要水印，不要工具栏，不要按钮，不要任何可读文字、字母或数字，以避免乱码。所有节点、备注和图例只使用抽象色块与短线表示内容。
```

## 推荐参数

- 画幅：16:9
- 建议尺寸：1600×900 或更高
- 风格：扁平化矢量、信息可视化
- 用途：仓库封面、README 头图、技能介绍页
